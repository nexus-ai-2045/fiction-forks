# Fiction Forks

> フィクションの部品を、未来を変える実装仮説として比較するオープン社会シミュレーション。

Fiction Forks は、2026年の日本を起点に、アニメ・漫画・小説・ゲームから着想した制度や技術を実装したとき、2036年までの社会がどう分岐するかを検証するプロジェクトです。

作品の人気や物語の続きを競うのではありません。参加者は「作品中の何を、誰が、何年かけて、どの技術ツリーで実装するか」を介入カードとしてPull Requestで提案します。基準世界と介入世界へ同じショックと乱数seedを与え、利益、費用、副作用、破滅時期の違いを比較します。

## 目的

フィクションを、専門・国籍・世代の違う参加者が同じ未来問題を指せる共通言語にすることです。既存作品から抽出した機能を、実装年数、制度、費用、失敗条件を持つ反証可能な介入へ変換し、「面白いアイデア」で終わらない未来設計を作ります。

## できること

- 無介入の日本2036世界線を、同じseedで再現する
- 作品由来の介入を加え、破滅年と5つの状態値を比較する
- 技術・制度・運用ノードの依存関係から介入発動年を計算する
- 特定ノードの遅延を注入し、実装が間に合わない世界線を試す
- 介入JSONと比較結果をPull Requestにして、新しい未来分岐を追加する

## 最初の問い

2036年までの日本で、防災、電力、物流、通信、情報分析を支える国家危機対応AIを一極集中させるか、複数主体へ分散させるか。

- 集中型は速く効率的ですが、攻撃、政治的捕捉、海外AI停止時に代替不能になり得ます。
- 分散型は遅く高コストですが、自治体、企業、市民、複数AIが相互監査し、一部が壊れても修復できます。
- 無介入の基準世界では、緊急性とコスト削減に押され、少数のAI基盤へ事実上集中していきます。

このシナリオは予言ではありません。現実の論点を比較可能な仮説へ変換した、透明なテスト環境です。

現実との接点、Fiction Forks独自の推論、破滅条件の反証方法は [docs/scenario-rationale.md](docs/scenario-rationale.md) に分離しています。

## 一つのPRが、一つの未来分岐になる

```text
知っている作品から「未来を変えそうな部品」を一つ取り出す
  -> 作品を知らない人にも通じる制度・技術の問いへ翻訳する
  -> 技術・制度・運用の依存ツリーと完成証拠を書く
  -> 基準世界と同じショック・seedで実行する
  -> 費用、副作用、間に合わない場合を含めてPull Requestにする
  -> 新しい世界線として比較可能になる
```

たとえば『呪術廻戦』なら「不可視リスクを専門家だけが知る社会」、『日本沈没』なら「巨大リスクを誰がいつ信じて移転へ変えるか」という入口を作れます。例は [docs/fiction-lenses.md](docs/fiction-lenses.md) にまとめています。

## 公式根拠

本プロジェクトがハッカソンと「メタ安全保障」の公式根拠として扱うのは、次の2点だけです。

- [AIエージェント社会シミュレーションハッカソン Vol.2 公式サイト](https://hackathon.automata-lab.jp/)
- [公式サイトからリンクされる構想ペーパー「メタ安全保障 — 概念解説とハッカソン課題の発想集」](https://prtimes.jp/a/?f=d80352-184-caedebb354dd205d5811c599da74761b.pdf)（片山俊大氏 v1.0ペーパー）

公式サイトまたは上記ペーパーにない説明、数値、シナリオ、破滅条件、フィクション介入は、Fiction Forks独自の仮説です。詳しい境界は [docs/official-sources.md](docs/official-sources.md) を参照してください。

## シミュレーション契約

各ターンでは、次の順序で状態を更新します。

```text
前年の状態
  -> 基準世界の構造変化
  -> 共通の外部ショック
  -> 技術ツリーを満たした介入
  -> 状態値の更新
  -> 破滅条件の判定
```

初期MVPは5つの状態値を扱います。

| 状態値 | 表すもの |
|---|---|
| `living_systems` | 電力、食料、物流、通信、医療などの生活基盤 |
| `strategic_autonomy` | 海外技術・資源が止まっても動ける度合い |
| `cognitive_sovereignty` | 共通事実を保ち、情報操作を発見できる能力 |
| `legitimacy` | 政策決定を監査し、異議を申し立てられる度合い |
| `repair_capacity` | 失敗を観測し、代替し、制度を更新できる能力 |

生活基盤、認知主権、修復能力のうち2項目が閾値を下回り、それが2ターン続くと破滅です。単純な総合点ではなく、「自分たちで未来を修正できなくなったか」を判定します。

## クイックスタート

Python 3.11〜3.13だけで実行できます。

```powershell
$env:PYTHONPATH = "src"
python -m fiction_forks compare `
  --scenario scenarios/japan-2036/scenario.json `
  --intervention interventions/doraemon-public-tools.json `
  --seed 2036
```

基準世界だけを確認する場合:

```powershell
$env:PYTHONPATH = "src"
python -m fiction_forks simulate `
  --scenario scenarios/japan-2036/scenario.json `
  --seed 2036
```

初期例の比較結果は次のとおりです。数値は現実予測ではなく、因果仮説を追跡するためのテスト値です。

| 2036年の結果 | 無介入 | 『ドラえもん』レンズ介入 |
|---|---:|---:|
| 破滅判定 | 破滅（2036年） | 回避 |
| 生活基盤 | 43 | 38 |
| 戦略的自律性 | 17 | 40 |
| 認知主権 | 6 | 11 |
| 正統性 | 38 | 43 |
| 修復能力 | 33 | 63 |

介入は生活基盤を5点悪化させます。平時の維持費を無料扱いしないためです。一方、修復能力は30点、戦略的自律性は23点改善し、破滅条件に入る指標を一つへ減らします。

最後の共同運営・訓練が5年遅れる世界線も試せます。この場合、介入は2036年の破滅に間に合いません。

```powershell
$env:PYTHONPATH = "src"
python -m fiction_forks compare `
  --scenario scenarios/japan-2036/scenario.json `
  --intervention interventions/doraemon-public-tools.json `
  --delay-node joint-governance-and-drills=5 `
  --seed 2036
```

## フィクション介入

介入は作品全体を再現せず、一つの機能を実装仮説へ変換します。

初期例では『ドラえもん』から「未来の道具へ日常的にアクセスできる」という構造を取り出し、自治体共同の公共AI・工作拠点として制度的に翻訳しています。画像、台詞、キャラクターの再現、公式協力の示唆は含みません。

この介入は次の順でしか発動しません。

```text
監査可能な公共AI参照実装（2029） ─┐
地域データ信託の運用規約（2030） ─┼→ 共同運営契約・監査人材・危機訓練（2032）
分散工作・修理拠点（2030） ─────┘
```

コードや装置だけでは未完成です。権限、異議申立て、単一事業者停止を含む訓練まで観測できて初めて効果を発生させます。

介入には必ず次を記述します。

- 参照作品と抽出した機能
- `literal` / `functional_equivalent` / `institutional_equivalent` の実現方式
- 必要な技術・制度と実装年数
- 各ノードの依存先と、完成を確認する証拠
- 状態値への効果
- 費用、副作用、失敗条件

詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

## 再現性と限界

- 同じscenario、intervention、seedは同じ結果を返します。
- 数値更新はルールエンジンが担当し、LLMに状態値を創作させません。
- 数値と因果は仮説です。公式統計、専門家レビュー、実測によって更新します。
- 実在国、企業、個人に関する評価は確認済み事実とシナリオ仮説を分離します。
- 出力は政策助言、災害予測、軍事予測ではありません。
