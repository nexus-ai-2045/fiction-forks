# 日本2036シナリオの根拠と反証条件

最終確認日: 2026-08-23

この文書は、`japan-2036-centralization` の現実との接点と、Fiction Forksが追加した設計仮説を分離する。ここに挙げる政府・公的機関資料はシナリオの参考資料であり、ハッカソンやメタ安全保障の「公式根拠」ではない。

## 観測できる出発点

### R-01 エネルギー自給率

- 観測: 資源エネルギー庁は、2024年度の日本のエネルギー自給率を16.4%としている。
- シナリオへの接続: 海外供給制約を `living_systems` と `strategic_autonomy` へ接続する。
- この観測だけでは言えないこと: 特定年に不足が起きること、AI集中が不足を引き起こすこと。
- 出典: 資源エネルギー庁「[日本のエネルギー2025 2.安定供給](https://www.enecho.meti.go.jp/about/pamphlet/energy2025/02.html)」

### R-02 海上輸送への依存

- 観測: 国土交通省資料は、日本の貿易量の99.6%を海上輸送が担うとしている。
- シナリオへの接続: 供給制約と複合災害を、物流・燃料・修理部品へ同時に波及させる。
- この観測だけでは言えないこと: 単一航路や単一事象による具体的な損失量。
- 出典: 国土交通省「[船舶産業の変革実現のための検討会 報告書](https://www.mlit.go.jp/maritime/content/001754797.pdf)」5ページ

### R-03 国際通信と海底ケーブル

- 観測: 内閣官房資料は、海底ケーブルが日本の国際通信の99%を担う基幹的インフラだと整理している。
- シナリオへの接続: 通信障害を、海外AI利用、情報検証、物流調整の共通ボトルネックにする。
- この観測だけでは言えないこと: 特定ケーブルの脆弱箇所、障害確率、攻撃主体。
- 出典: 内閣官房「[戦略17分野における主要な製品・技術等の官民投資ロードマップ（案）](https://www.cas.go.jp/jp/seisaku/nipponseichosenryaku/kaigi/dai5/shiryou3.pdf)」情報通信・海底ケーブル

## Fiction Forksが置く設計仮説

観測事実から破滅は直接導けない。本シナリオは、次の連鎖を比較実験のために仮置きする。

```text
海外資源・海運・国際通信への高依存
  + 危機対応AIと運用知の少数基盤への集中
  -> 供給・通信ショック時の代替遅延
  -> 被害認識と資源配分をめぐる情報操作
  -> 複合災害後の復旧失敗
  -> 誤りを発見して未来を修正する能力の固定的喪失
```

年、閾値、効果量は現実の予測値ではない。初期MVPでは因果を追跡しやすくするためのテスト値として固定する。

## 破滅の定義

人口消滅や国家消滅を破滅とは呼ばない。`living_systems`、`cognitive_sovereignty`、`repair_capacity` のうち2項目が35未満になり、2年続いた状態を、**社会が自力で誤りを観測・代替・修正できない固定点に入った**と定義する。

この定義により、短期的な経済損失だけ、支持率だけ、軍事力だけでは破滅にならない。一方で、生活基盤が一部残っていても、共通事実と修復回路を同時に失えば破滅になり得る。

## 反証・更新条件

- 一つの指標だけで結論が決まり、三指標の連鎖を説明できないなら破滅条件を作り直す。
- seedを変えると介入の優劣が容易に逆転するなら、単一結果を主張せず感度分析を追加する。
- 技術だけを置けば制度・運用ノードなしでも同じ結果になるなら、技術ツリーの効果設計を差し戻す。
- 公開統計や専門家レビューが因果方向を否定するなら、数値調整で延命せず因果鎖を更新する。
- 介入が費用・副作用・失敗条件なしで全指標を改善するなら、万能介入として不採用にする。
