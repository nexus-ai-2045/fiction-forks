# 公式根拠の境界

## 公式として扱うもの

1. [AIエージェント社会シミュレーションハッカソン Vol.2 公式サイト](https://hackathon.automata-lab.jp/)
2. [公式サイトから「構想ペーパーを読む」としてリンクされるPDF](https://prtimes.jp/a/?f=d80352-184-caedebb354dd205d5811c599da74761b.pdf)
   - タイトル: 「メタ安全保障 — 概念解説とハッカソン課題の発想集」
   - 本プロジェクトでの識別: 片山俊大氏 v1.0ペーパー
   - PDF記載の発行: Singulab / AUTOMATA

## 公式として扱わないもの

- Discordへ投稿された別版、添付、会話
- 紹介記事、報道記事、SNS投稿、参加者の要約
- Fiction Forksが作成した日本2036scenario、数値、破滅条件、介入効果

公式以外の資料を調査や着想に使うことはできますが、「参考」「独自仮説」「未検証」のいずれかとして分離し、公式説明へ混ぜません。

日本2036シナリオで使う政府・公的機関の公開資料は [scenario-rationale.md](scenario-rationale.md) に置きます。これらは現実との接点を確認する一次資料であり、ハッカソンやメタ安全保障の公式原典には数えません。
