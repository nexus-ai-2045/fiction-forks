# ADR 0005: 破滅を修復可能性の喪失として判定する

- Status: Accepted
- Date: 2026-08-24

## Context

放置世界が悪化するだけではゲーム上の期限が生まれない。一方、人口やGDPの総合点だけで破滅を決めると、社会が誤りを発見し、代替し、制度を修正できるかという本テーマが消える。

## Decision

破滅は国の消滅ではなく「自力で修正できない状態」と定義する。日本2036の初期scenarioでは、`living_systems`、`cognitive_sovereignty`、`repair_capacity`のうち2項目以上が35未満となり、それが2turn続いた時点で破滅と判定する。

閾値、対象指標、連続turn数、ショック年、効果量は予測ではなくMVPの仮説であり、scenarioデータへ明示する。根拠と反証条件を別文書へ記録する。

## Consequences

- 介入を期限へ間に合わせる緊張が生まれる。
- 一つの高得点が複数の修復不能を隠さない。
- 破滅という強い語に、限定したモデル上の意味を常に併記する必要がある。
- 閾値変更は既存結果へ大きく影響するためreviewと互換性判断が必要になる。

## Alternatives considered

- 5指標の平均点: 代替不能な低指標を高指標で相殺できるため不採用。
- 単年の閾値超過: 一時ショックと固定化を区別できないため不採用。
- 破滅条件なし: 介入時期とクリティカルパスの意味が弱くなるため不採用。

## 見直し条件

別の国・地域・期間では、同じ破滅条件を流用せず、対象社会の因果仮説と反証条件を持つscenarioとして定義する。
