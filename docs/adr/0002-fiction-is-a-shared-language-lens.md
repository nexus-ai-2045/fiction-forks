# ADR 0002: フィクションを共通言語レンズとして使う

- Status: Accepted
- Date: 2026-08-24

## Context

作品名が分かると、長い技術・制度論を短い共有イメージから始められる。一方、画像、台詞、キャラクター、物語を再現すると、権利、文化差、作品知識の有無が参加障壁になる。

## Decision

作品名と、Fiction Forksが独自に抽出した抽象的な機能を「フィクション・レンズ」として参照する。各レンズには、作品を知らない人向けの同義表現と、本プロジェクト独自の実装仮説を併記する。

公式画像、漫画コマ、台詞、音声、映像、音楽、ロゴ、キャラクター表現、特徴的な口調、公式協力の示唆はrepoへ収録しない。

## Consequences

- 『ドラえもん』『呪術廻戦』など認識しやすい入口を保持できる。
- 作品を知らない人も現実の問いから参加できる。
- 作品の正確な要約や二次創作ではなく、独自の構造抽出であることを明示する必要がある。
- MIT Licenseは第三者IPへ適用されない。

## Alternatives considered

- 完全オリジナル設定だけを使う: 権利境界は単純だが、共通言語としての価値を失うため不採用。
- 原作素材を使って没入感を高める: 公開repoでの権利と参加境界が不明確になるため不採用。

## 見直し条件

権利者から具体的な利用許諾または公式協力が得られた場合も、対象素材、地域、期間、表示方法を別文書と新ADRで限定する。
