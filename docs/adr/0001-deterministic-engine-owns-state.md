# ADR 0001: 決定的ルールエンジンが状態遷移を所有する

- Status: Accepted
- Date: 2026-08-24

## Context

LLMエージェントの自由会話へ社会状態の更新を任せると、同じ入力でも結果が変わり、効果量の由来と破滅理由を追跡できない。Fiction Forksは予言ではなく、異なる介入を同じ条件で比較する道具である。

## Decision

scenario、intervention、seed、遅延条件からの状態更新、技術ツリー完了年、破滅判定は決定的なPythonルールエンジンが所有する。同じ有効入力とengine versionは同じ結果を返す。

将来LLMを追加しても、制約内の行動候補、説明、要約だけを担当させる。LLMは状態値、効果量、破滅条件、根拠の公式性を確定しない。

## Consequences

- 結果をCI、ローカル、将来UIで再現できる。
- 因果仮説と数値の変更をGit diffでレビューできる。
- 自由度の高いエージェント社会表現より透明性を優先する。
- engine変更は互換性、golden result、ADRを伴う。

## Alternatives considered

- LLMが毎turnの数値を生成する: 再現性と反証可能性が不足するため不採用。
- 人間が結果を記述するだけ: 比較実行と遅延実験ができないため不採用。

## 見直し条件

確率モデルを導入する場合も、seedと分布を固定して再現可能な契約にできることを新ADRで示す。
