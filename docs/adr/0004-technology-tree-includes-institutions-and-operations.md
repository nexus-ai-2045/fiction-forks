# ADR 0004: 技術ツリーに制度と運用を含める

- Status: Accepted
- Date: 2026-08-24

## Context

未来技術の試作品が存在しても、権限、データ利用、責任、異議申立て、人材、共同運営、停止訓練がなければ社会的な効果は安定して発生しない。装置だけのtech treeは実装年を過小評価する。

## Decision

技術ツリーノードは次の3種とする。

- `technology`: 試作品、相互運用、物理設備
- `institution`: 権限、監査、データ利用、異議申立て
- `operations`: 人材、共同運営、訓練、引継ぎ

全ノードは依存先、非負の実装年数、観測可能な`completion_evidence`を持つ。介入は`activation_requires`の全ノードが完成した年からだけ発動する。

## Consequences

- 社会実装のクリティカルパスを表示できる。
- 「技術はあるのに使えない」失敗をモデル化できる。
- 制度・運用の年数と効果量も仮説として根拠とreviewが必要になる。
- ノード遅延が破滅時期へ与える影響を同じseedで試せる。

## Alternatives considered

- 技術TRLだけを追う: 権限と運用の遅延を表現できないため不採用。
- 完成率の単一パーセント: 依存先と未完了理由が消えるため不採用。

## 見直し条件

財務、文化受容、国際合意を独立node kindにする必要が生じた場合、既存3種で表現できない例を複数示してschema変更を判断する。
