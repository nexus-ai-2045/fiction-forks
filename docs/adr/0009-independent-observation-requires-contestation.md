# ADR 0009: 世界観測は独立照合・来歴・異議申立てが揃うまで発動しない

- Status: Accepted
- Date: 2026-08-24

## Context

「世界の変化を観測する力」を社会実装へ翻訳すると、センサーやAIの精度だけを上げる案へ寄りやすい。しかし、複数の観測系が同じ供給者へ依存していれば一致は独立した裏付けにならず、異議申立てや訂正がなければ観測能力は監視と権威の集中を強める。観測結果から政策判断へ飛躍すれば、決定論engineが状態を所有するADR 0001と、AIが制約付き行動だけを選ぶADR 0008にも反する。

## Decision

1. 世界観測介入は、単一の万能観測者ではなく、独立運営される複数系統の照合として実装する。
2. 観測値と同時に、欠測、校正誤差、証拠来歴、変換履歴、対立仮説、少数意見、訂正履歴を保存する。
3. 観測される側の訂正・撤回・異議申立てと、人間による停止権を制度ノードの必須条件にする。
4. 地域ラボ間の交換校正と、一系統停止・誤警報・未合意を含む共同訓練を完了するまで介入効果を発動しない。
5. 観測の一致は事実仮説の信頼度を上げ得るが、政策判断の正しさ、未来予測、作品世界の再現を保証しない。
6. AIエージェントは固定action catalogから観測・来歴・異議・訓練の行動を選ぶだけとし、状態値と破滅判定は既存engineへ残す。

## Consequences

- 技術精度だけでは介入が発動せず、制度と運用の遅延が結果へ現れる。
- 不一致や少数意見を失敗として消さず、検証対象として追跡できる。
- 複数系統の維持費、誤警報、意思決定遅延、監視社会化を副作用として評価できる。
- 観測対象、保存期間、独立性の測定方法には現実の法制度・運用レビューが別途必要になる。

## Alternatives considered

- **高性能な中央観測AIへ集約する**: 共通原因故障と権威集中を強め、独立照合にならないため不採用。
- **多数決で観測不一致を解消する**: 系統数と独立性を混同し、少数の正しい警告を消し得るため不採用。
- **観測結果から政策を自動執行する**: 観測と価値判断の境界を失い、取り消し可能性を下げるため不採用。
- **自由会話するAIに世界状態を採点させる**: 再現性と同一seed比較を失うため不採用。

## 見直し条件

- 異なる観測主体の独立性を測る公開手法が成立しないと分かったとき
- 訂正・撤回手続が危機対応を実質的に不可能にする実測が得られたとき
- 観測データの保存自体が、得られる修復能力を上回る権利侵害を生むと確認されたとき
